# Healthcare Waiting List Analytics Dashboard

## Project Overview
An end-to-end Power BI dashboard analysing hospital inpatient and outpatient waiting lists to track patient wait times, specialty demand, and monthly trends.

## Objective
- Monitor the current vs previous year monthly waiting list.
- Analyse average and median wait times by specialty and age profile.
- Identify top specialties with the highest waiting lists.
- Track trends across case types (Inpatient, Outpatient, Day Case).

## Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query (Data Transformation)
- PowerPoint (Dashboard Layout Design)

## Data Source
Patient Wait List Data — Pivotalstats
(https://pivotalstats.com/end-end-power-bi)

## Dashboard Pages
1. **Summary Page** — KPI cards, charts, top specialties.
2. **Detail Page** — Drill-down matrix by date, specialty, age and time bands.

## Key Features
- Dynamic Average/Median toggle button
- Drill-through from summary to detailed view
- Interactive slicers for date, case type, specialty and age profile
- Custom PowerPoint background design

## Skills Demonstrated
- Data modelling and transformation
- DAX measures and calculated columns
- Dashboard design and interactivity
- Publishing to Power BI Service
